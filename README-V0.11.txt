FILA CERO v0.11 — Premium responsive

Cambios de interfaz:
- Menú móvil hamburguesa en Marketplace, Login, Dashboard, Perfil público y Administración.
- Navegación móvil en panel desplegable con cierre por Escape, selección o toque fuera.
- Ajustes responsive desde 320 px: hero, filtros, tarjetas, formularios, modales, dashboard y admin.
- Mejoras de foco, botones táctiles, espaciado, sombras y legibilidad.
- Footer común con “Hecho por Dev Web CCP” enlazado a https://www.instagram.com/dev_web_ccp/
- Sin cambios SQL ni cambios en tablas/RLS de Supabase.

Para publicar:
1) Reemplaza los archivos del repositorio por esta versión (conserva .git).
2) git add .
3) git commit -m "Fila Cero v0.11 responsive premium"
4) git push
5) Espera el despliegue de Cloudflare y fuerza recarga con Ctrl+F5.
